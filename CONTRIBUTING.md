# Contributing

Thanks for helping make homebrew development on Chromatic easier.

## Useful contributions

- Try the GB Studio build helper on macOS, Windows, or Linux.
- Share compatibility results from original homebrew on a documented Chromatic revision.
- Improve setup instructions without promising unverified hardware behavior.
- Help make the transfer path usable on macOS, ideally by building on documented interfaces or contributing upstream.

## Reports

Include the host operating system, Chromatic model/revision, firmware version, GB Studio version, ROM format, and exact steps. Do not attach copyrighted game ROMs or private save files.

## Code

The command-line helper uses only Python's standard library. Keep actions that can rewrite firmware or cartridges explicit and opt-in. Do not add automatic firmware flashing.
